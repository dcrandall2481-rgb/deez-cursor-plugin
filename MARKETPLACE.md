# Marketplace listing copy

**Name:** Deez

**One-liner:** Space-engineering rules, skills, and a local two-body MCP so Cursor agents stop inventing orbital numbers.

**Description:**

Deez is a Cursor plugin for NewSpace, university, and ground-software teams. It adds always-on units/frames discipline, high-reliability habits for cyclic GNC code, task skills (orbit check, GNC skeleton, cFS/F Prime stubs, conjunction hygiene, license checklist, handling gate), and a dependency-free local MCP server.

The MCP computes ideal two-body circular orbits and Hohmann transfers, audits mixed units, and flags handling keywords. It is not official SpaceX software and does not ship proprietary data.

**Keywords:** aerospace, astrodynamics, gnc, flight-software, cubesat, orbit

**Install:** `/add-plugin deez`
